## О проекте

Проект представляет собой веб-приложение на Django для управления клиентами, услугами, рекламными кампаниями, потенциальными и активными клиентами, контрактами и статистикой.

Система должна автоматизировать процессы:

- учёта предлагаемых компанией услуг;
- запуска и контроля рекламных кампаний;
- учёта потенциальных клиентов;
- перевода потенциальных клиентов в активных;
- оформления контрактов;
- анализа эффективности рекламных кампаний.

---

## Основной функционал

В приложение должны быть реализованы:

1. авторизация пользователей;
2. создание, редактирование и просмотр предоставляемых услуг;
3. создание, редактирование и просмотр рекламных кампаний;
4. создание, редактирование и просмотр потенциальных клиентов;
5. создание, редактирование и просмотр контрактов;
6. перевод потенциального клиента в активного;
7. подсчёт и отображение статистики по рекламным кампаниям.

---

## Роли пользователей

В системе предусмотрены роли:

| Роль | Права |

|---|---|
| Администратор | создаёт пользователей, назначает роли и разрешения через административную панель Django |
| Оператор | создаёт, просматривает и редактирует потенциальных клиентов |
| Маркетолог | создаёт, просматривает и редактирует услуги и рекламные кампании |
| Менеджер | создаёт, просматривает и редактирует контракты, просматривает потенциальных клиентов и переводит их в активных |
| Все роли | могут смотреть статистику рекламных кампаний |

Пользователи и роли создаются через стандартный административный интерфейс Django.

Остальные функции CRM-системы должны быть доступны вне административной панели Django.


## Установка и запуск проекта

Если команда `python` не работает, используй `python3`.

---

### 1. Клонировать репозиторий

Если проект находится в удалённом репозитории, выполни:

```bash
git clone адрес_репозитория
cd crm_system
```

Если проект уже находится в текущей папке, клонирование не требуется.

---

### 2. Создать виртуальное окружение

```bash
python -m venv venv
```

---

### 3. Активировать виртуальное окружение

Для Windows и обычной командной строки:

```bash
venv\Scripts\activate.bat
```

Для Windows PowerShell:

```bash
venv\Scripts\Activate.ps1
```

Для Linux и macOS:

```bash
source venv/bin/activate
```

---

### 4. Установить зависимости

```bash
pip install -r requirements.txt
```

---

### 5. Настроить подключение к базе данных

В файле `config/settings.py` нужно указать параметры подключения к базе данных.

Необходимо заполнить:

```text
Название базы данных: crm_db
Пользователь: crm_user
Пароль: твой пароль
Хост: 127.0.0.1
Порт: 5432
```

Позже параметры подключения можно будет вынести в отдельный файл `.env`.

---

### 6. Создать миграции

```bash
python manage.py makemigrations
```

Если команда `python` не работает:

```bash
python3 manage.py makemigrations
```

---

### 7. Применить миграции

```bash
python manage.py migrate
```

Если команда `python` не работает:

```bash
python3 manage.py migrate
```

Эта команда создаст таблицы в базе данных.

---

### 8. Создать администратора

Для входа в административную панель нужно создать суперпользователя:

```bash
python manage.py createsuperuser
```

Далее указать:

1. имя пользователя;
2. email;
3. пароль.

---

### 9. Загрузить тестовые данные из фикстур

```bash
python manage.py loaddata fixtures/test_data.json
```

Если команда `python` не работает:

```bash
python3 manage.py loaddata fixtures/test_data.json
```

На текущем этапе фикстура может быть пустой:

```json
[]
```

После создания моделей и наполнения базы данных фикстура будет заполнена тестовыми записями.

---

### 10. Запустить сервер разработки

```bash
python manage.py runserver
```

Если команда `python` не работает:

```bash
python3 manage.py runserver
```

После запуска открыть в браузере:

```text
http://127.0.0.1:8000
```

Административная панель доступна по адресу:

```text
http://127.0.0.1:8000/admin
```

Для остановки сервера нажать:

```text
Ctrl + C
```

## Фикстуры

Фикстуры находятся в папке:

```text
fixtures/
```

Основной файл тестовых данных:

```text
fixtures/test_data.json
```

Для загрузки фикстур используется команда:

```bash
python manage.py loaddata fixtures/test_data.json
```

Для создания фикстур после наполнения базы данных используется команда:

```bash
python manage.py dumpdata auth.group crm --indent 2 > fixtures/test_data.json
```

Если команда `python` не работает:

```bash
python3 manage.py dumpdata auth.group crm --indent 2 > fixtures/test_data.json
```

Пояснение:

- `auth.group` используется для выгрузки ролей пользователей;
- `crm` используется для выгрузки данных приложения.
